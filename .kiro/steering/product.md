# Product Overview

Keylol Telegram Bot is an automated forum-to-Telegram bridge application that monitors the Keylol forum for new posts and forwards them to a Telegram channel.

## Core Features
- Automated forum monitoring with configurable intervals
- Forum login with captcha handling via Telegram admin notifications
- Formatted post forwarding to Telegram channels
- Duplicate post prevention
- Admin notifications for system events and errors

## Key Components
- Forum scraping and authentication
- Telegram bot integration using Pyrogram
- Scheduled task execution
- Post processing and formatting
- Session persistence and error recovery

## Target Use Case
Designed for community managers who want to automatically share forum content to their Telegram channels without manual intervention.
